# 使用漫画源与 Venera 致谢

轻阅支持导入 JavaScript 漫画源，并对 Venera 风格的基础宿主接口提供兼容实现。

上游项目及社区：

- [Venera 应用](https://github.com/venera-app/venera)
- [venera-configs 源脚本社区](https://github.com/venera-app/venera-configs)

感谢 Venera 及各源作者的设计、维护和文档工作。上游应用采用 GPL-3.0；源配置仓库没有统一的仓库级许可证声明，应逐个查看作者信息和授权条件。轻阅没有把上游应用或整套脚本重新声明为 MIT。

## 导入单个源

1. 在上游仓库选择你有权使用的源脚本，查看其作者声明和许可；下载对应的原始 `.js` 文件。
2. 在轻阅中打开「设置 → 内容来源 → 导入源文件」。
3. 选择下载的脚本，核对源名称、版本和允许访问的域名。
4. 确认安装后，在「发现」页选择该来源，再执行搜索。

也可使用内容来源页的 HTTPS 链接输入框加载脚本或兼容的源索引。GitHub 仓库网页本身不是 JavaScript 文件，请使用原始文件链接或先下载到本地。

## 兼容范围

已实现基础搜索、作品详情、目录、图片读取、部分 HTML 解析接口、MD5／AES-ECB 和图片分块重排。某些源依赖更完整的宿主接口、登录、专用解密或站点限制，可能需要适配；因此不能承诺任意 Venera 源都能直接运行。

仓库内的 `examples/comic-sources/` 是本项目自行编写的适配示例。请保留你安装或修改的第三方脚本的原作者与许可证，遵守来源站点的访问条件，不要在公开 Issue 上传账号、Cookie 或个人书架。
